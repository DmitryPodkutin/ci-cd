# ci-cd

Демонстрационное Spring Boot-приложение с одним контроллером.

## Что внутри

- `GET /status` — возвращает сообщение о том, что приложение запущено, с датой и временем старта.
- Слой сервиса: `StatusService` фиксирует время запуска и подставляет его в шаблон сообщения.
- Шаблон сообщения вынесен в `src/main/resources/application.yml` и содержит плейсхолдеры `%s` для даты и времени.

## Требования

- JDK 17+

## Запуск

Со сборщиком Gradle, установленным локально:

```bash
gradle bootRun
```

Либо сгенерируйте обёртку и запускайте через неё:

```bash
gradle wrapper
./gradlew bootRun
```

## Проверка

Приложение слушает порт `8080`:

```bash
curl http://localhost:8080/status
```

Ответ — сообщение из `application.yml`, в котором `%s` заменены на фактические дату и время запуска приложения.
